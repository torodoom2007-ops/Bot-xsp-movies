# Movie Time 🍿 — Telegram Movie Library

בוט Telegram ממותג, עם קליטת קבצים מהמנהל, תור שמות, חיפוש בקבוצה/פרטי, כפתורי תוצאות, שידורים וסטטיסטיקה.

## מה נדרש

- חשבון Render לפריסת שירות Web.
- Bot Token מ־@BotFather.
- מסד PostgreSQL חיצוני מתמשך. **אין לשמור SQLite בקבצי Render Free**: מערכת הקבצים שם זמנית ונמחקת בהפעלה מחדש/פריסה/כיבוי.
- להוספת הבוט לקבוצה `-1004309235247` עם הרשאות לשליחת הודעות.
- לכבות Privacy Mode ב־@BotFather (`/setprivacy` → לבחור את הבוט → `Disable`) כדי לקבל הודעות טקסט רגילות בקבוצה. אם הקבוצה היא ערוץ, התנהגות העדכונים שונה ויש להתאים זאת.

## אחסון וקבצים

הבוט שומר ב־PostgreSQL את שם הסרט, מזהה הקובץ של Telegram (`file_id`), סוג המדיה, ומטא־נתוני המקור. הסרט עצמו לא מורד ל־Render ולא נוצר עותק מקומי — זה חסכוני ומתאים למאגר גדול. `file_id` מאפשר לשלוח את הקובץ מחדש דרך Telegram, אבל אינו גיבוי עצמאי של המדיה: מומלץ לשמור גם עותק מקור של הסרטים במערכת אחסון נפרדת אם הם חשובים.

השתמשו ב־Supabase Postgres או ספק PostgreSQL מתמשך אחר. במסלול החינמי של ספקי אחסון ייתכנו השהיה, מגבלות מכסה, מחיקה/פקיעה, או דרישה לשדרוג. בדקו את תנאי הספק וייצאו גיבוי תקופתי של בסיס הנתונים. אין שירות חינמי שמבטיח "לעולם לא יימחק".

## פריסה ב־Render

1. העלו את קובצי הפרויקט ל־GitHub repository פרטי.
2. ב־Render לחצו **New → Web Service** וחברו את המאגר.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
5. הוסיפו Environment Variables:
   - `BOT_TOKEN` — הטוקן מ־BotFather (לעולם אל תפרסמו אותו).
   - `ADMIN_ID` — `8017590244`
   - `GROUP_ID` — `-1004309235247`
   - `BOT_USERNAME` — `Ms_blon_bot`
   - `BRAND_URL` — `https://t.me/movie_time_by`
   - `DATABASE_URL` — כתובת PostgreSQL עם SSL לפי הוראות הספק.
   - `WEBHOOK_SECRET` — סוד ארוך אקראי (אפשר ליצור מחרוזת אקראית).
6. ודאו שהשירות פעיל ושהנתיב `/health` מחזיר `Movie Time is alive`.
7. ב־Telegram פתחו את הבוט בפרטי ושלחו `/start`.
8. הוסיפו אותו לקבוצה והגדירו Privacy Mode כבוי.

`render.yaml` מספק Blueprint התחלתי. אם Render לא מאפשר ליצור אוטומטית את המשתנים הסודיים, הגדירו אותם ידנית.

## שימוש

### מנהל
- `/admin` — לוח ניהול.
- לחצו **התחלת קליטה**, שלחו עד 50 קבצים, ואז `/finish`.
- הבוט יעבור על הקבצים לפי סדר, יציג כל קובץ שנשלח וישאל לשם הסרט. שלחו רק את השם.
- `/broadcast` — ההודעה הבאה תשוכפל בפרטי לכל המשתמשים שהפעילו את הבוט.
- `/groupbroadcast` — ההודעה הבאה תישלח לקבוצה.
- `/cancel` — ביטול מצב ההמתנה, בלי למחוק סרטים שכבר נשמרו.

### משתמשים
- `/start` כדי לאפשר לבוט לשלוח הודעות פרטיות.
- כתבו שם סרט בקבוצה או בפרטי.
- בחרו תוצאה; הבוט שולח את הקובץ בפרטי.

## מגבלות חשובות

- משתמש חייב לפתוח את הבוט לפחות פעם אחת לפני שהבוט יכול לשלוח לו הודעה פרטית.
- משתמש שחסם את הבוט לא יקבל שידור; הוא מסומן כלא זמין לשידורים עתידיים.
- כפתורי callback פועלים עד שטלגרם/הבוט מאפשרים את הפעולה; אם המשתמש לא פתח את הבוט, יופיע קישור לפתיחה.
- Render Free עשוי להירדם לאחר חוסר תנועה. Webhook מפחית תלות ב־polling, אך אינו מבטיח שירות ללא השהיה או זמינות 24/7.
- החיפוש החכם כאן משלב התאמה מלאה/חלקית ודמיון טקסט. הוא אינו מנוע AI ואינו מתקן כל שגיאת כתיב.
- `file_id` הוא הפניה של Telegram, לא קובץ גיבוי עצמאי. עבור תוכן שחייב להישמר לאורך שנים, החזיקו עותק מקור וגיבוי DB חיצוני.
